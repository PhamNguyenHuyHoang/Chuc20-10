# Gửi cô gái anh yêu — 20.10

Website kỷ niệm gói gọn trong một màn hình: lúc đầu chỉ hiện phong thư; khi bấm, lời chúc và một ảnh kỷ niệm chuyển động hiện ra. Ảnh tự lật sang ảnh tiếp theo sau 2 giây. Nền cánh hoa anh đào rơi liên tục. Không cần cuộn trang.

## Chạy website

Chạy `start-website.bat` hoặc mở PowerShell tại thư mục này và nhập `npm run dev`. Trang mở tại `http://localhost:5173`; lưu file sẽ tự cập nhật.

## Nội dung

- Ảnh: `assets/photos/` (12 ảnh trong slideshow; đã loại moment-06, moment-08 và moment-11)
- Nội dung trang và lời chúc: `index.html`
- Bố cục và hiệu ứng: `style.css`
- Cánh hoa, hiệu ứng mở thư và chuyển ảnh: `script.js`
